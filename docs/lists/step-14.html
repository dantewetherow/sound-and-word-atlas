Legomorphic spelling · A step’s pattern

Step 14: The box blocks the vault

Two consonants between vowels block the vault, so the first vowel stays short. A short word doubles its last consonant to build the block: get, getting.

This list goes with Step 14: The box blocks the vault.

Print this list: the teacher’s notes are left off.

The words

spell + ing → spellingWe have spelling today.
get + t + ing → gettingIt is getting late.
help + ed → helpedShe helped me.
sun + n + y → sunnyIt is a sunny day.
hap + p + y → happyI am happy.
hop + p + ing → hoppingThe frog is hopping.
runningrun + n + ing → runningStop running.
sittingsit + t + ing → sittingWe are sitting on the mat.

The contrast

One consonant lets the vault through; two block it.

Did it generalize?

For the teacher

Help and spell already end in two consonants, so nothing doubles: the block is there already.

The check ends with fixing: x never doubles, because it already spells two sounds.

Have the learner build each word from its sum, not copy it, and say each sentence before writing it. Six to eight words is the whole list: the convention is what’s being learned.
