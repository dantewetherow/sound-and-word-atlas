Legomorphic spelling · One root, many words

The *deuk- family: produce, product, production, reduce

One root, to lead, with two spellings: duce for the verb (produce) and duct before an ending (production).

This list goes with The *deuk- family.

Word study: From duct to education, a presentation for learners.

Print this list: the teacher’s notes are left off.

The words

pro + duce → produceFarms produce food.
pro + duct → productThis product is new.
pro + duct + ion → productionThe school play was a big production.
re + duce → reduceReduce your speed.
re + duct + ion → reductionThe price had a reduction.
introduceintro + duce → introduceIntroduce your friend.
introductionintro + duct + ion → introductionRead the introduction.
conductorcon + duct + or → conductorThe conductor waved.

The contrast

duce for the verb, duct before -ion.

Build it

  1. pro + duce →
  2. pro + duct + ion →
  3. re + duce →
  4. re + duct + ion →
  5. con + duct + or →
  6. e + duc + ate →

Use it

  1. Bees (pro + duce) honey.
  2. Read the (intro + duct + ion) first.
  3. The (con + duct + or) led the band.
  4. We need to (re + duce) waste.

Check: not on the list

  1. de + duct →deduct
  2. pro + duc(e) + er →producer
  3. e + duc + at(e) + ion →education
  4. con + duct →conduct

Did it generalize?

This list has a check: 12 words to give before the lesson, after it, and a few weeks later. Most of them aren’t on the list, so it shows whether the convention was learned or only the words.

For the teacher

The verb drops its e before -er (producer) and takes duct before -ion (production).

The check ends with conduct, a noun and a verb with one spelling: CONduct, conDUCT. The stress moves; the spelling doesn’t.

Have the learner build each word from its sum, not copy it, and say each sentence before writing it. Six to eight words is the whole list: the convention is what’s being learned.
