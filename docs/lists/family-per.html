Legomorphic spelling · One root, many words

The *per- family: experiment, experimental, experience, experienced

*per- means to try, to risk. Latin made it peri (experiment, experience), pert (expert) and peril; Greek made it pir (empirical); English kept fear.

This list goes with The *per- family.

Word study: Try it out, a presentation for learners.

Print this list: the teacher’s notes are left off.

The words

ex + peri + ment → experimentWe did an experiment with ice.
ex + peri + ment + al → experimentalThe plane is experimental.
ex + peri + ence → experienceCamp was a good experience.
ex + peri + enc(e) + ed → experiencedHe is an experienced pilot.
ex + pert → expertAsk an expert.
ex + pert + ise → expertiseWe need her expertise.
peril + ous → perilousThe path up the hill was perilous.
em + pir + ic + al → empiricalScience needs empirical tests.

The contrast

One spelling, two sounds: per is closed in experiment, pe is open in experience.

Check: not on the list

  1. ex + peri + ment + ation →experimentation
  2. ex + peri + ent + ial →experiential
  3. ex + pert + ise →expertise
  4. fear + ful →fearful

For the teacher

Experiential has a t where experience has a c: -ence and -ential, as in essence and essential.

The check ends with fearful: the same root by English’s own road.

Have the learner build each word from its sum, not copy it, and say each sentence before writing it. Six to eight words is the whole list: the convention is what’s being learned.
