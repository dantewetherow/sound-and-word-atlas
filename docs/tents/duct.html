Morpheme cards: duct

The parts of the duct matrix on the *deuk- page, as cards that stand up. The base comes first, then the prefixes and suffixes found with it. Stand them in a row to build a word from the matrix, then try a path the matrix doesn’t list and test it.

Print the cards: eight to a page. Cut along the solid lines, fold along the dotted line, and stand each card up.

duct

Tap the parts to build a path, left to right. Any box can be skipped.
